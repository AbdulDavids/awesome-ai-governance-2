# Contribution Guidelines

PRs welcome. The standard for inclusion is "would I send this to a CTO under pressure".

- Entry format: `- [Name](url) - Description ending in a full stop.`
- One line of why-it-is-here per entry, not just what it does.
- Links must be live. Repos must show a commit within the last twelve months.
- No tool listings without justification. No marketing pages.
- Open an issue first if in doubt.
